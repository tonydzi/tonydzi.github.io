Agent infrastructure

Stop every agent session from spawning its own copy of every MCP server

Each Claude or Codex session starts its own stdio copy of every MCP server. With 50 sessions open the machine swaps, the fans spin and nobody knows why.

Book a 15-minute Google MeetRead the code

Is this for you

  • Anyone running many parallel agent sessions on one machine
  • Teams with Telegram, MongoDB, n8n or browser MCP servers in their config
  • Ops people who were told "just buy more RAM"
The first win we aim for: One shared MCP daemon per machine instead of one per session, and a measured RAM drop on your own machine.
