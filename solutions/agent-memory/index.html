Agent memory

Agent memory that knows when a fact stopped being true

Your agent remembers that a customer moved, then answers with the old address. Most memory layers store facts; few can answer "what did we believe on 1 March" or cleanly retract a wrong fact.

Book a 15-minute Google MeetRead the code

Is this for you

  • Teams shipping agents that talk to the same users for months (CRM, support, sales assistants)
  • Anyone evaluating Mem0, Zep/Graphiti or a homegrown store and needing an honest comparison on their own data
  • Regulated workflows where you must show what the agent knew at a given date
The first win we aim for: Your agent answers an "as of date D" question correctly on your own records, and a retracted fact stays retracted.

What we do not claim

  • On LoCoMo temporal questions Mem0 beats us (76.5 vs 72.2, borderline significance); we publish it anyway.
  • The retraction result ties Mem0; it shows the scenario works, not that we are better.
  • The LoCoMo row and the retraction row are two different engines of ours, labelled as such.
  • DolphinBench numbers are source-session recall, not the full DolphinBench pass rate.
  • LongMemEval has not been run yet; it is next on the list.
