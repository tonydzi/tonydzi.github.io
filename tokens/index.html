  • Codex and OpenRouter calls made on machines other than the hub

Method

  • Claude. Each machine runs token_usage_ledger.py nightly over its Claude Code transcripts, deduplicates usage records by message id (streaming writes the same record several times), and drops one hourly row per session and model into the fleet bus. This page merges all slices and collapses a machine that reports under two hostnames into one.
  • Codex. Codex CLI logs a cumulative token_count after every turn. We take the deltas between consecutive events, so a session that spans weeks is split correctly.
  • OpenRouter. Our router llm_ask.py writes one line per call with the input and output tokens and the price the API returned.
  • Machine-readable: tokens.json (this snapshot) and history.json (every week ever recorded). The instruments are open source: llm-spend-audit.
